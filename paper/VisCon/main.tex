\begin{abstract}
SAM's ViT-H encoder, pre-trained on over one billion masks, learns strong visual features, but its decoder fails to produce correct masks when objects are camouflaged. We isolate this failure by freezing the encoder and fine-tuning only the 4M-parameter mask decoder on COD10K. This raises mIoU from 57.2\% to 73.8\% and reduces prompt sensitivity from 3.5$\times$ to 1.1$\times$ across four prompt types. The decoder generalizes without retraining: +16.9 mIoU on CAMO and +17.4 on NC4K. Our findings indicate baseline feature representations contain all the information necessary to detect and segment the objects, and while the general-purpose decoder does not translate them into correct boundary predictions, simply fine-tuning the decoder gives improvements that generalize across datasets.
\end{abstract}

\section{Introduction}

Foundation segmentation models learn to represent boundaries, texture transitions, and spatial layout from large-scale supervision. SAM~\cite{kirillov2023sam,ravi2024sam2}, trained on over one billion masks, segments almost anything. Yet camouflaged objects expose a clear failure: on COD10K~\cite{fan2020cod10k}, SAM ViT-H achieves only 57.2\% mIoU with center-of-mass prompts and 20.5\% with edge prompts (\cref{tab:main_viscon}). Camouflaged organisms have evolved to defeat visual detection, and SAM's default ability to segment these masks is affected as well.

Does the encoder lack the relevant features, or does the decoder fail to use them? If the ViT-H encoder, pre-trained on 11M images, already encodes the texture gradients that distinguish camouflaged foreground from background, then specializing only the decoder should recover most of the gap. That is what we observe.

Prior SAM adaptation methods typically modify the encoder via adapters~\cite{chen2023samadapter}, redesign prompt pathways~\cite{hao2024comprompter}, or add dual-stream modules~\cite{liu2025dualstream}. These approaches improve performance but conflate two questions: whether the encoder needs better features, and whether the decoder needs better feature utilization. By changing only the decoder, we isolate the latter.

Decoder specialization also reduces prompt sensitivity (\cref{tab:main_viscon}). An ablation over training regimes (\cref{tab:prompt_ablation_viscon}) shows mixed point/box training consistently outperforms point-only and box-only alternatives. The specialized decoder generalizes to held-out camouflage datasets (CAMO, NC4K) without retraining.

\noindent\textbf{Contributions.}
\begin{enumerate}[nosep]
    \item We develop a decoder-only adaptation approach for segmenting camouflaged objects, achieving +16.6 mIoU on COD10K with no architecture changes, 90-minute training, and a 16MB checkpoint.
    \item We demonstrate this improvement is robust across datasets (CAMO, NC4K) and prompt styles.
\end{enumerate}

\section{Related Work}

\noindent\textbf{Camouflaged object detection.}
Dedicated COD architectures (SINet~\cite{fan2020cod10k}, PFNet~\cite{mei2021pfnet}, SINet-V2~\cite{fan2022sinetv2}, ZoomNet~\cite{pang2022zoomnet}, SegMaR~\cite{jia2022segmar}) design task-specific detection networks. Recent work has also explored camouflage from the generation side~\cite{das2025camouflage}, using SAM representations to produce context-consistent camouflage textures. We take the complementary direction: rather than generating camouflage, we ask how far decoder-only adaptation can go for detecting it without domain-specific architecture.

\noindent\textbf{SAM adaptation.}
SAM-Adapter~\cite{chen2023samadapter} injects learnable modules inside the encoder, COMPrompter~\cite{hao2024comprompter} redesigns the prompt pathway, and Liu~\etal~\cite{liu2025dualstream} add dual-stream adapters. Each modifies the encoder or prompt pathway, which improves performance but conflates feature quality with feature utilization. We modify only the existing decoder, isolating the utilization question.

\noindent\textbf{Parameter-efficient fine-tuning.}
LoRA~\cite{hu2022lora} and prompt tuning~\cite{lester2021prompt} adapt large models by adding small parameter sets to the encoder or prompt pathway. Our approach is simpler: we add zero new parameters and train only the existing 4M-parameter mask decoder.

\section{Method}
SAM consists of a ViT-H image encoder~\cite{dosovitskiy2020vit} ($\sim$632M parameters), a prompt encoder, and a mask decoder ($\sim$4M parameters). We freeze the image encoder and prompt encoder, and train only the mask decoder (\cref{fig:architecture}).

\noindent\textbf{Pre-computed embeddings.} We run the frozen encoder once on all training images and cache embeddings as \texttt{.npy} files, eliminating the encoder forward pass from training.

\noindent\textbf{Mixed-prompt training.} Each iteration randomly selects between a point prompt (random foreground pixel) and a bounding box prompt (tight GT box) with 50/50 probability. This guards against the decoder overfitting to one prompt type and gives us a direct test of whether gains transfer across prompt styles.

\noindent\textbf{Loss and optimization.} We minimize $\mathcal{L} = 0.5 \cdot \mathcal{L}_{\text{BCE}} + 0.5 \cdot \mathcal{L}_{\text{Dice}}$, where BCE enforces pixel-level boundaries and Dice maintains region-level coherence. Ablations over four weighting variants (BCE-only, Dice-only, 0.7/0.3, 0.3/0.7) show all fall within $\pm$2.1 mIoU of the 0.5/0.5 baseline; the choice is not sensitive. We use AdamW (lr $10^{-4}$, cosine schedule, 1-epoch warmup, 15 epochs). Training takes $\sim$90 minutes on a single A100 with pre-computed embeddings.

\noindent\textbf{Evaluation protocol.} We evaluate four prompt strategies of increasing difficulty: \textbf{Center-of-Mass} (1pt), \textbf{Edge} (1pt on boundary contour), \textbf{Multi-Grid} (4pt), and \textbf{Multi-Random} (3pt). Following SAM's standard protocol~\cite{kirillov2023sam}, prompts are derived from ground-truth masks to simulate idealized user clicks. We report mIoU, $S_\alpha$~\cite{fan2017smeasure}, $E_\phi$~\cite{fan2018emeasure}, $F_\beta^w$~\cite{margolin2014fmeasure}, and MAE on the 2,026-image COD10K test set, CAMO~\cite{le2019anabranch} (250), and NC4K (4,121).

\section{Discussion}

\noindent\textbf{What this reveals about visual concept representation.}
The ViT-H encoder, having seen 1B+ masks during pre-training, appears to already encode texture gradients and edge patterns that matter for camouflage. The decoder, trained on general segmentation, has not learned that \emph{subtle} texture disruptions signify boundaries. The 16.6-point mIoU gain from training only 0.6\% of parameters (\cref{tab:main_viscon}) is consistent with the bottleneck being in feature utilization (decoder) rather than feature representation (encoder), though direct probing of the encoder's internal representations would be needed to confirm this.

\noindent\textbf{Effect of prompt mixing.}
Mixed-prompt training reduces prompt sensitivity from 3.5$\times$ to 1.1$\times$ (\cref{tab:main_viscon}). Point-only and box-only training each produce decoders that perform well on only on their own prompt type (\cref{tab:prompt_ablation_viscon}). Mixed training improves results on all prompts, with the largest gains on prompt styles not seen during training.

\noindent\textbf{Where the decoder still fails.}
Analyzing the bottom quartile of predictions (400 worst images) reveals structured failure modes, not random noise. Disjoint objects (multiple connected components) account for 44\% of failures; dark images (brightness $<$ 80) account for 26\%. Tiny objects ($<$1\% of image area) are the hardest category, with a mean IoU of 0.29. These patterns point to single-point prompting and fixed-resolution decoding as the remaining bottlenecks, not missing encoder features.

\noindent\textbf{Beyond camouflage: a diagnostic lens.}
The decoder-only protocol is not specific to camouflage. Any domain where a foundation model underperforms can be tested the same way: freeze the encoder, fine-tune only the decoder, measure recovery. If most of the gap closes, the bottleneck is downstream; if not, the encoder itself needs adaptation. Medical imaging and underwater scenes involve similar low-contrast boundaries and could be tested in the same way. The per-category results (\cref{tab:category}) show the diagnostic is granular enough to reveal which \emph{types} of visual difficulty benefit most.

\noindent\textbf{Complementary directions.}
A lightweight preprocessing module before the frozen encoder adds +2{-}4 mIoU in preliminary experiments; we leave its analysis to future work. Encoder-adaptation methods~\cite{chen2023samadapter,hao2024comprompter} achieve higher absolute $S_\alpha$, so encoder and decoder specialization address different parts of the problem.

\noindent\textbf{Limitations.}
(1)~Our evaluation uses oracle GT-derived prompts following SAM's standard protocol; deployment requires a prompt source.
(2)~Results are from single training runs without confidence intervals.
(3)~We do not directly probe what the encoder represents; linear probes or attention visualization would strengthen the claim that encoder features are sufficient.
(4)~Cross-dataset evaluation covers camouflage only; we have not tested non-biological camouflage (e.g., military) or the medical/underwater domains suggested above.

\section{Conclusion}
Freezing SAM's encoder and fine-tuning only its 4M-parameter decoder raises mIoU by 16.6 points on COD10K, generalizes to held-out datasets, and reduces prompt sensitivity from 3.5$\times$ to 1.1$\times$. That this improvement comes from modifying only 0.6\% of parameters is consistent with the encoder already containing the features needed for camouflage segmentation. Direct evidence via linear probes or attention visualization remains future work.

\begin{abstract}
Camouflaged object segmentation is a useful stress test for subtle visual concepts in foundation models: foreground and background differ mainly by weak texture and boundary cues rather than strong semantic contrast. We ask a focused question: \emph{is the decoder the bottleneck?} Using camouflaged object detection as a probe, we freeze SAM's ViT-H encoder and fine-tune only its 4M-parameter mask decoder. This decoder-only adaptation raises mIoU on COD10K from 57.2\% to 73.8\% (+16.6 points) while reducing prompt sensitivity from a 3.5$\times$ range across prompt types to 1.1$\times$. A prompt-mix ablation shows that this robustness is learned rather than incidental: mixed point/box training outperforms point-only by up to 4 mIoU and box-only by 19--37 mIoU. These results suggest that, for promptable camouflaged segmentation, much of the missing capability lies not in the frozen encoder representation but in the decoder's ability to convert subtle cues into object masks.
We evaluate under SAM's standard prompt-based protocol, using ground-truth-derived simulated clicks to probe promptable segmentation behavior rather than fully automatic COD.
\end{abstract}

\section{Introduction}
SAM~\cite{kirillov2023sam} segments a remarkable range of objects, but camouflaged scenes expose a sharp failure mode. On COD10K~\cite{fan2020cod10k}, base SAM achieves only 57.2\% mIoU with center-of-mass prompts and 20.5\% with edge prompts. In these images, the object is not missing semantic content; rather, it is hidden by weak, spatially distributed visual cues that are easy to ignore. This makes camouflage a useful probe of what a foundation segmentation model already represents and where adaptation matters.

This paper asks a simple question: \textbf{is the decoder the bottleneck?} SAM's frozen ViT-H encoder may already encode useful low-level cues for camouflage, but the general-purpose decoder may fail to map these cues into object masks. If so, adapting only the mask decoder should recover substantial performance without modifying the encoder. Our results support this view. Decoder-only fine-tuning yields a +16.6 mIoU gain on COD10K, and this gain transfers across diverse prompt types rather than depending on a single prompt heuristic.

This perspective differs from prior SAM adaptation work, which often improves underperformed domains by modifying the encoder, adding adapters, or redesigning prompt pathways~\cite{chen2023samadapter,hao2024comprompter}. Here, camouflage is not just an application benchmark; it is a probe of \emph{where} the missing capability lies. Our goal is therefore not to maximize COD performance by any means necessary, but to test how far one can go by adapting only the existing decoder.

For a concept-focused workshop, the most important result is not just the absolute gain, but \emph{how} the gain behaves. Base SAM is highly prompt-sensitive, varying from 0.205 to 0.727 mIoU across our four prompt strategies. After decoder specialization, this narrows to 0.694--0.776. An ablation confirms that this robustness is learned: mixed point/box training is consistently stronger than point-only and dramatically better than box-only. We interpret this as evidence that the specialized decoder learns object structure under subtle cues instead of simply memorizing prompt geometry.

\noindent\textbf{Contributions.}
\begin{enumerate}
    \item We propose camouflaged segmentation as a stress test for subtle visual concept formation in SAM and ask whether the missing capability lies primarily in the decoder.
    \item We show that decoder-only adaptation of SAM yields a +16.6 mIoU gain on COD10K while keeping the encoder frozen.
    \item We show that prompt robustness is a key piece of evidence for this claim: mixed-prompt training reduces prompt sensitivity from 3.5$\times$ to 1.1$\times$ and outperforms point-only and box-only alternatives.
\end{enumerate}

\section{Method}
SAM consists of an image encoder, a prompt encoder, and a mask decoder. We freeze both encoders and train only the mask decoder (\cref{fig:architecture}). To keep training lightweight, we pre-compute image embeddings from the frozen ViT-H encoder and cache them as \texttt{.npy} files. Each training iteration samples either a point prompt (random foreground pixel) or a box prompt (tight ground-truth box) with 50/50 probability. This mixed-prompt regime is important: it prevents the decoder from overfitting to a single prompt format and lets us test whether robustness transfers to unseen prompt styles.

We train with a 50/50 BCE+Dice loss, AdamW, cosine learning-rate decay, and 15 epochs. At test time, we evaluate four prompt strategies of increasing difficulty: Center-of-Mass, Edge, Multi-Grid, and Multi-Random. Our focus is not on fully automatic COD, but on what promptable evaluation reveals about SAM's internal bottlenecks.

\Cref{tab:main_viscon} is the core result. Freezing the encoder and adapting only the decoder yields strong gains across all prompt types, with the largest improvement on the hardest case: edge prompts. This is exactly where subtle boundary interpretation matters most. The result suggests that useful visual information is already present in the frozen representation, but the default decoder does not know how to use it for camouflage.

Prompt robustness is the second key piece of evidence. Base SAM varies 3.5$\times$ across prompt types (0.205 to 0.727 mIoU), while the specialized decoder varies only 1.1$\times$ (0.694 to 0.776). \Cref{tab:prompt_ablation_viscon} shows that this is not an accidental by-product of fine-tuning: mixed prompt training consistently outperforms both point-only and box-only training. In particular, box-only training collapses on point prompts, indicating that robustness must be learned through exposure to multiple prompt modalities. We interpret this as evidence that the decoder is learning object structure under subtle visual cues rather than simply reacting to prompt placement.

\section{Discussion}
Our results do not prove that the encoder is never a limitation. Instead, they support a narrower but useful conclusion: for \emph{promptable camouflaged segmentation}, decoder adaptation is a particularly effective intervention. The frozen encoder appears to already contain subtle texture and edge information that can support camouflage reasoning, but the original decoder does not convert that information into masks reliably.

This framing also explains why camouflage is such a useful testbed for concept-oriented analysis. In ordinary scenes, strong semantic contrast can hide representational weaknesses. In camouflaged scenes, successful segmentation depends on weak, spatially distributed evidence. If adapting only the decoder substantially improves performance and prompt robustness, then the missing capability is likely downstream of feature extraction. This makes the decoder a natural place to study how subtle visual concepts are translated into segmentation decisions.
